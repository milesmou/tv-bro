# 国内视频平台广告过滤

本轮为默认 WebView 版本增加七个平台的内置补充规则，不替换用户配置的 EasyList 或自定义订阅。

同时默认订阅 EasyList China，默认地址为 `https://easylist-downloads.adblockplus.org/easylistchina.txt`，备用源为项目 GitHub 原始文件。设置 → 主要 → 广告屏蔽中可单独填写 EasyList China 镜像地址；该地址优先，失败或内容不是 EasyList China 时回退官方源和备用源。目前未核实到可靠、在维护的大陆托管镜像，故未把第三方代理作为默认源；本机已验证官方源返回有效规则，不保证所有大陆运营商的可达性。

EasyList China 每四天检查更新，原有主订阅保持独立。两份原始文本分别原子缓存，合并后一次编译，保留 `@@` 例外规则。更新失败使用对应旧文本和已编译规则；首次迁移时，如果只能获取中文规则但无法取得主订阅原文，暂时保留原主订阅缓存，下一次启动重试。设置显示两份订阅各自的下载更新时间，刷新按钮同时更新两份订阅。现有引擎的网络规则支持范围不因订阅完整文本而改变，未新增通用脚本规则或通用元素隐藏解释器。

EasyList 主订阅默认使用官方地址 `https://easylist-downloads.adblockplus.org/easylist.txt`，同时保留 `https://easylist.to/easylist/easylist.txt` 作为官方备用源。先尝试设置中第一项地址，再按顺序尝试这两个官方地址，重复地址只请求一次。自定义规则地址优先且不被改写；两个已知官方地址会检查列表标题，避免错误列表被当作 EasyList。尚未核实到可靠的大陆托管 EasyList 镜像，因此未把第三方代理作为默认源。用户指定镜像后可填入第一项并刷新，两份订阅都会更新。

网络规则必须同时匹配当前视频平台和请求地址；正常主页面导航不参与拦截。页面隐藏只对对应站点注入 CSS，动态加入且符合选择器的元素自动受 CSS 约束，没有额外轮询或 MutationObserver。

现有广告开关同时控制内置补充与订阅规则。菜单中的当前标签广告开关可用于播放异常排查，关闭后刷新页面即可重新请求资源。修正了后台标签错误使用当前标签广告开关的问题。

这组规则没有删除登录、付费提示或播放器控件，也不修改播放器 API、媒体清单及广告倒计时。不保证过滤片头广告、视频内嵌广告或服务端拼接广告。网页改版后需要重新核验选择器。Gecko 变体沿用共享网络过滤路径，本轮页面 CSS 注入和设备验证针对 WebView。

规则参考 [EasyList China](https://github.com/easylist/easylistchina/blob/master/easylistchina.txt)，截至 2026-10-09。仅选取一小部分路径与普通 CSS 规则，并收窄适用站点。归属与许可证随 APK 打包于 `assets/adblock/NOTICE.txt`；未宣称完整支持 AdGuard/uBlock 的脚本规则语法。

订阅更新增加连接和读取超时，先启用已有缓存，成功解析并保存后才替换正在使用的规则并更新日期。更新失败保留旧规则；内置规则不依赖联网下载。

验证包含七个平台正例、相似域名与路径反例、播放及登录地址不受内置规则影响，以及浏览器中七组 CSS 广告位隐藏与移除后恢复。以上为规则和模拟页面验证，不能替代各平台登录账号、会员状态和不同视频的线上播放实测。

订阅接入后构建与 32 项单元测试通过，新增测试覆盖镜像失败、错误订阅、HTML 错误页、备用源与合并保留例外。Android 模拟器实际下载约 541 KB 中文规则和约 2.12 MB 主规则，成功生成约 3.43 MB 合并缓存；3840×2160 下检查了设置显示，并验证方向键依次进入中文订阅地址和更新按钮，测试后恢复模拟器分辨率。
