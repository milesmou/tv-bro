# 稳定性与遥控器回归检查

## 自动检查

构建前读取 `.gradle/local-env.json` 中的本机环境配置，运行：

```powershell
.\gradlew.bat :app:testGenericGeckoExcludedDebugUnitTest :app:assembleGenericGeckoExcludedDebug :app:gecko:compileDebugKotlin
```

新增测试覆盖：

- 同次下载任务内断线续传、服务器忽略 Range 时重新下载、错误范围拒绝、无验证标识时重新下载、HTTP 重试和取消。
- 未知长度、超过 2GB 的大小解析、永久截断失败、流与 Blob 下载的文件清理和完成通知。
- 广告开关不影响安全浏览，子资源错误不弹出整页提示，网页进程退出回调被接管。
- 标签状态文件独立保存、重复保存更新状态，以及 4K 缩略图尺寸与内存预算。

## 主页方向键检查

在调试 APK 中打开主页，使用 `adb shell pidof com.milesmou.tvbrowser` 获取进程号，再转发对应的调试端口：

```powershell
adb forward tcp:9222 localabstract:webview_devtools_remote_<进程号>
node scripts/check_home_navigation.mjs
```

脚本需要支持内置 `fetch` 和 `WebSocket` 的 Node.js。它临时替换网页 DOM 中的卡片，检查焦点边界、不满一行时的向下导航、排序后的书签焦点和编辑控件焦点，结束后恢复卡片和焦点缓存；不会调用书签编辑接口或写入书签数据库。
