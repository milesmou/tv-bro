# 启动与网页交互验证

2026-10-09，验证构建：`genericGeckoExcludedDebug`。

## 行为

- 冷启动打开一个新的主页标签；应用仍在运行时，从桌面再次打开保留原来的页面和标签，不重新导航。
- 冷启动不读取旧 WebView 会话来恢复网页。旧标签记录及缓存文件通过会话锁在后台清理。
- Activity 因配置变更重建时保留当前活动标签；外部链接仍按链接打开。
- 主页数据与标签初始化并行，历史维护延后执行。
- 弹窗拦截读取预加载的站点设置；更新下载配置超时、取消断连、长度及 APK 包名检查。
- Blob 通过 64 KiB 分块传输，原生队列最多保留四块；背压、取消、超时和不完整传输均有处理。
- 视频控制条刷新合并执行，忽略自身样式写入；网页长按菜单可按站点关闭常显控制条，选择后刷新页面。

## 启动采样

同一 Android 模拟器、1600×900、240 dpi，每组五次强制停止后的进程冷启动，安装后的首次启动不计入。
指标是日志中 Application `onCreate` 到内置主页最后一次 `onPageFinished`，不是系统开机耗时或精确首帧呈现时间。

| 版本 | 五次耗时（毫秒） | 中位数 | 主页完成回调次数 |
| --- | --- | --- | --- |
| 修改前 | 1697、1376、1482、1116、1553 | 1482 ms | 2 |
| 修改后，仅主页 | 1492、1119、1061、1241、1212 | 1212 ms | 1 |

该组样本中位耗时下降约 18.2%；模拟器存在抖动，真实电视上的收益需要单独测量。
本机原始日志保存在 Git 忽略的 `.gradle/startup-review/`。
