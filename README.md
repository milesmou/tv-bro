# 浏览器 · TV Bro 中文本地化版

本项目基于开源电视浏览器 [tv-bro](https://github.com/truefedex/tv-bro) 进行中文本地化，面向 Android TV 和电视盒子使用。应用名称为「浏览器」。

当前版本：**1.0.0**；应用包名：`com.milesmou.tvbrowser`。可在 [GitHub Releases](https://github.com/milesmou/tv-bro/releases) 下载正式 APK。

在原项目的基础上，参考 BrowseHere 的界面布局与遥控器交互，对 UI 和操作方式进行了优化，让电视上的浏览、导航和设置更方便。

## 本版本的主要改进

- **中文界面**：调整菜单、设置、对话框和提示文案，便于中文用户使用。
- **电视界面优化**：采用统一的深色风格、卡片布局和清晰的焦点边框，菜单按钮与标签栏保持等高。
- **遥控器优先**：应用内部页面使用方向键移动焦点、确认键执行操作；第三方网页使用圆点光标模拟点击。
- **设置操作优化**：使用适合遥控器的选项列表，顶部选项随焦点自动切换，开关所在行提供明显的焦点高亮。
- **中文搜索**：默认使用必应中国，支持自定义搜索引擎。
- **主页快捷卡片**：预置腾讯视频、爱奇艺、优酷、芒果 TV、哔哩哔哩、虎牙和斗鱼；支持添加、编辑、删除和调整顺序。
- **桌面网页浏览**：默认采用 Chrome 桌面版 UA，保留桌面 UA 和自定义 UA 选项。
- **显示适配**：布局、文字和焦点样式适配不同屏幕密度，菜单图标优先采用矢量资源，支持 4K 界面显示。

## 浏览功能

- 标签页、书签和浏览历史。
- 内置下载管理。
- 广告屏蔽与弹窗拦截。
- 常见网页播放器的控制条保持可见，方便遥控器操作。
- 可配置的遥控器快捷键。
- 基于 Android System WebView 的网页渲染；项目同时保留包含 Gecko 引擎的构建变体。

## 常用操作

- **方向键**：在应用内部界面移动焦点，在第三方网页移动圆点光标。
- **确认键**：打开选中的卡片、按钮或选项。
- **长按确认键**：在主页快捷卡片上打开操作菜单，可删除、编辑、向前移动或向后移动。
- **添加卡片**：选择主页末尾的「添加」卡片，新增快捷链接。
- **返回键**：关闭当前弹窗或返回；在主页按返回键会显示退出确认框。

## 构建

配置 Android SDK 和项目所需的 JDK 后，在项目根目录执行：

```powershell
.\gradlew.bat :app:assembleGenericGeckoExcludedDebug
```

生成的 APK 位于：

```text
app/build/outputs/apk/genericGeckoExcluded/debug/app-generic-geckoExcluded-debug.apk
```

该构建使用 Android System WebView，不包含 Gecko 引擎。

正式版本的签名配置、标签发布与手动发布步骤见 [发布说明](docs/RELEASING.md)。
